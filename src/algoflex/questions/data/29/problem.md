### Tree level-order traversal
Given the `root` of a binary tree, traverse the tree using level order traversal and return the values as an array.

### Example
```
root = [12, 8, 16, 4, 9, 13, 18, 1]

                12
               /  \
              8    16
             / \   / \
            4   9 13  18
           /
          1

output = [12, 8, 16, 4, 9, 13, 18, 1]
```
