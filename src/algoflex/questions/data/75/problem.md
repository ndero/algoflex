### Cycles in linked list
Given the `head` of a linked list, return `true` if there is a cycle in the linked list or `false` otherwise.

**Example 1**

* **Input:** `head = 3 -> 2 -> 1`
* **Output:** `false`

**Example 2**
* **Input:** 
```text
    head = 3 -> 2 -> 1
                ↑____↓
```
* **Output:** `true`

**Constraints**

* `0 <= n < 10^5` where `n` is the number of nodes in the linked list.
