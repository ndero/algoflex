### Valid matching brackets
Given a string `s` of brackets that can either be `[]`, `()` or `{}`.
Check if the brackets are valid.

There no other characters in the string apart from '[', ']', '(', ')', '{'and '}'.

**Example 1**

* **Input:** `s = "[](){}"`
* **Output:** `True`

**Example 2**

* **Input:** `s = "{{}}[][](()"`
* **Output:** `False`

**Constraints**

* `0 <= s.length <= 10^5`
