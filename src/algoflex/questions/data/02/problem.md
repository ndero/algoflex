### Valid matching brackets
Given a string `s` of brackets that can either be `[]`, `()` or `{}`.
Check if the brackets are valid.

There are no other characters in the string apart from '[', ']', '(', ')', '{' and '}'.

**Example 1**

* **Input:** `s = "[](){}"`
* **Output:** `true`

**Example 2**

* **Input:** `s = "{{}}[][](()"`
* **Output:** `false`

**Constraints**

* `0 <= s.length <= 10^5`
