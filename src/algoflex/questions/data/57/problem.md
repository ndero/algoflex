### Merge intervals
Given an array of `intervals`, merge all overlapping intervals.

**Example 1**

* **Input:** `intervals = [[1, 5], [5, 10]]`
* **Output:** `[[1, 10]]`

**Example 2**

* **Input:** `intervals = [[1, 2], [4, 5], [1, 3]]`
* **Output:** `[[1, 3], [4, 5]]`

**Constraints**

* `0 <= intervals.length <= 10^5`
* `intervals[i].length == 2`
* `0 <= intervals[i][j] < 10^5`
