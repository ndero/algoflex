### Longest Substring Without Repeating Characters
Given a string `s`, find the length of the **longest substring** that contains no repeating characters.

A **substring** is a contiguous sequence of characters within a string. The answer must be the length of such a substring, not the substring itself.

Can you do it in `O(n)` time complexity?

### Examples
```text
Input: s = "abcddeee"
Output: 4
How: The longest substring without repeating characters is "abcd", with length 4.
```

```text
Input: s = "aaa"
Output: 1
How: The longest substring without repeating characters is "a", with length 1.
```

```text
Input: s = ""
Output: 0
```

### Constraints
```text
0 <= s.length <= 5 * 10^4
s consists of English letters, digits, symbols, and spaces.
```
