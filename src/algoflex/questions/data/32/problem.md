### Sum right nodes
Given the `root` of a binary tree, return the sum of all the right nodes

### Example
```
root =  [12, 8, 16, 4, 9, 13, 18, 11]

                12
               /  \
              8    16
             / \   / \
            4   9 13  18
           /
          11

output = 43 (16 + 9 + 18)
```
