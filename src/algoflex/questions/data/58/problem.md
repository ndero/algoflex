### longest increasing subsequence
Given an array `nums` of integers return the length of the longest strictly increasing subsequence.

**Example**

* **Input:** `nums = [10,9,2,5,3,7,101,18]`
* **Output:** `4`
* **How:** LIS is [2, 3, 7, 101] with length 4.

**Constraints**

* `0 <= nums.length <= 10^4`
* `0 <= nums[i] < 10^4`
