### Subarrays with sum
Given an array `arr` and `target`, return the total number of contigous subarrays inside the array whose sum is equal to `target`

**Example**

* **Inputs:** `arr = [13, -1, 8, 12, 3, 9]`, `target = 12`
* **Output:** `3`
* **How:** `[13, -1]`, `[12]` and `[3, 9]`

**Constraints**

* `0 < arr.length < 10^5`
* `-10 < arr[i] < 20`
* `-10 < target < 20`
