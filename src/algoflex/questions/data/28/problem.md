### Tree in-order traversal
Given the `root` of a binary tree, traverse the tree in order and return the values as an array.

### Example
```
root = [12, 8, 16, 4, 9, 13, 18, 1]

                12
               /  \
              8    16
             / \   / \
            4   9 13  18
           /
          1

output = [1, 4, 8, 9, 12, 13, 16, 18]
```
