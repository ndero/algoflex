### Has node BST
Given the `root` of a binary search tree and a value `x`, check whether the value x is in the tree and return `True` or `False`

### Example
```
root = [9, 8, 16], x = 5

      9
     / \
    8   16

output = False
```

```
root = [12, 3, 20], x = 3

      12
     /  \
    3    20

output = True
```
