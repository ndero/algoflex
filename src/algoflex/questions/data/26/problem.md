### Binary Search Tree minimum
Given the `root` of a binary search tree, find the minimum value and return it.

**Example**

* **Input:** `root = [12, 3, 20]`
```text
      12
     /  \
    3    20
```
* **Output:** `3`

**Constraints**

* `0 <= root.length <= 2 * 10^5`
* `root[i]` can be `None` or `-10^5 <= root[i] < 10^5`
