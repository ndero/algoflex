### Generate parentheses
Given a positive integer `n`, generate all combinations of well formed parentheses with `n` pairs.

**Example 1**

* **Input:** `n = 3`
* **Output:** `["((()))","(()())","(())()","()(())","()()()"]`

**Example 2**

* **Input:** `n = 1`
* **Output:** `["()"]`

**Constraints**

* `0 <= n <= 12`
