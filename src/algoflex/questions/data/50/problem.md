### Longest common prefix
Given an array of strings `strs` return the longest common prefix of all the strings.

**Example 1**

* **Input:** `strs = ["flower","flow","flight"]`
* **Output:** = `"fl"`

**Example 2**

* **Input:** `strs = ["dog","racecar","car"]`
* **Output:** `""`

**Constraints**

* `0 <= strs.length <= 10`
* `0 <= strs[i].length < 20`
