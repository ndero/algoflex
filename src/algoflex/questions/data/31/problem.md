### Tree leaves
Given the `root` of a binary tree, return all the leaves as an array ordered from left to right.

> A leaf is tree node with no children.

### Example
```
root = [100, 50, 600, 45, 55, 500, 1000]

                 100
               /     \
             50       600
            /  \     /    \
          45   55   500   1000

output = [45, 55, 500, 1000]
```

```
root = [7, 5, None, None, 6]

        7
      /   
    5 
      \
        6
  
output = [6]
```
