### Trap rain water
Given `n` positive integers `nums` representing elevation heights where the width of each bar is 1, return how much water can be trapped after rain.

**Example**

* **Input:** `nums = [3, 1, 2, 7]`
```text
      []
      []
      []
      []
[]    []
[]  [][]
[][][][]
```
* **Output:** `3`
* **How:** 2 units at index 1 and 1 unit at index 2

**Constraints**

* `0 <= nums.length <= 10^5`
* `0 <= nums[i] < 10^5`
