### Max sum sub array
Given a non empty integer array `nums`, find a contiguous non-empty subarray within the array that has the largest sum and return the sum.

**Example 1**

* **Input:** `nums = [-2, 0, -1]`
* **Output:** `0`

**Example 2**

* **Input:** `nums = [2, 3, -2, 4]`
* **Output:** `7`

**Constraints**

* `1 <= nums.length <= 10^5`
* `-2^31 < nums[i] < 2^31 - 1 `
